# アンケート設計書（少人数版）：3D浸水可視化映像は2Dハザードマップより分かりやすいか

研究題目：福知山市中心市街地における内水氾濫の3D可視化と**防災啓発ツールとしての有効性**に関する研究
作成：2026-10-18（案・少人数向け）

> この設計書は、企画書 README.md の 10章「効果の検証」を詳しくしたもの。
> 協力者が **10〜30人程度** と少ない前提で、**全員が2Dと3Dの両方を見て、同じ人の中で比べる**設計にしている。
> **【確定後に記入】** は、映像・地図に使う浸水深などの数値が決まってから正解を入れる項目。

## 1. 何を確かめるか

### 1.1 研究の位置づけ
人数が少ないため、この調査は **探索的な検証（予備調査）** と位置づける。
「3Dが2Dより有効だと証明する」のではなく、**どの点で分かりやすく、どの点ではそうでもないかを、数値と生の声の両方から明らかにする**ことを目的にする。卒論ではこの位置づけを「研究方法」の章にはっきり書く。

### 1.2 測る5つの面
「分かりやすかったか」という感想だけでは、「3Dは新しくて面白い」という印象の差しか分からない。防災啓発ツールとしての有効性を言うために、次の5つから測る。

| 面 | 何を見るか | 測り方 |
|---|---|---|
| ① 客観的な理解 | 浸水の深さ・場所・順番・内水の仕組みを**正しく読み取れたか** | 正解のあるテスト |
| ② 主観的な分かりやすさ | 分かりやすいと感じたか、読み取りが大変だったか | 5段階評価＋負担感 |
| ③ リスクの自分事化 | 危険を「自分のこと」と感じたか | 5段階評価 |
| ④ 避難の意図 | 早めに避難しよう、自宅の危険を調べようと思ったか | 5段階評価 |
| ⑤ 副作用 | 怖がらせすぎ、誤解（3Dの見た目を正確だと思い込む）、酔い | 5段階評価＋自由記述 |

### 1.3 問い（仮説の代わり）
少人数の探索的研究なので、「仮説を検証する」より「問いに答える」形にする。
- 問1：2Dの地図と3Dの映像で、浸水の**深さ・場所・広がり方・内水の仕組み**の分かりやすさはそれぞれどう違うか。
- 問2：3Dの映像は、危険を自分のことと感じさせ、避難しようという気持ちを高めるか。
- 問3：3Dで分かったつもりになる、不安になりすぎる、などの副作用はあるか。
- 問4：見た人は、3Dのどこが分かりやすく、どこを改善すべきだと感じたか（聞き取り）。

### 1.4 理論的な枠組み（先行研究で引用できるもの）
- **防護動機理論（Protection Motivation Theory, Rogers 1983）**：人が避難などの行動を取るかは「脅威評価（深刻さ・起こりやすさ）」と「対処評価（避難が有効か・自分にできるか）」で決まる、という考え方。③④の質問はこれに沿って作る。
- **正常性バイアス**：中間レポート1.2節で触れている。「自分は大丈夫」と思う度合いを質問に入れる。

## 2. 調査の設計

### 2.1 基本の形：全員が両方を見て、順番だけ入れ替える

```
全員：同意 → 事前アンケート
        │
   受付で割り当て表（2.2）の①〜⑥を順番に割り当て
   ├─ A群（①②③）：範囲1を 2D で見る → アンケート① → 範囲2を 3D で見る → アンケート② → 比較アンケート → 聞き取り（一部の人）
   └─ B群（④⑤⑥）：範囲1を 3D で見る → アンケート① → 範囲2を 2D で見る → アンケート② → 比較アンケート → 聞き取り（一部の人）
```

- **A群・B群に分ける理由は「順番の影響を打ち消すため」**。グループ同士を比べるためではない。
  順番を分けないと、「3Dが良かった」のか「2回目だから分かった」のかを区別できない。10人しかいなくても交互に割り当てる。
- **比べ方**：同じ人の「2Dを見た後の評価」と「3Dを見た後の評価」を比べる。人による差（もともとの知識・感じ方）が打ち消されるので、少ない人数でも差が見えやすい。
- A群とB群の人数はだいたい同じなら十分（例：11人と10人）。

### 2.2 理解度テストの扱い：範囲を3つ用意し、1人は2つを見る（採用）
同じ範囲を2回見ると、2回目は答えを覚えているので、**1人が見る2回は必ず別の範囲**にする。

**3つの範囲**（それぞれ **2Dの地図と3Dの映像を両方** 作る）
| 範囲 | 中心 | 含めたいもの |
|---|---|---|
| X | 福知山城周辺 | 城のふもとの低い土地（城公園の観光駐車場など）、内記の街なか。天守のある高台と、そのすぐ下の浸水の対比 |
| Y | 福知山市民病院周辺 | 弘法川・法川、和久市ポンプ場付近。中間レポートの3Dモデルのうち病院周辺の部分を使い回せる |
| Z | 桃映中学校周辺 | 通学路、避難所としての学校 |

> **福知山城周辺を範囲に入れる根拠**：天守は高台にあるが、ふもとは浸水している。2014年8月豪雨の市の被害資料に「福知山城公園観光駐車場トイレ 浸水」の記載がある。福知山市の公式サイトに「福知山城前の浸水の様子」の写真が掲載されている（https://www.city.fukuchiyama.lg.jp/uploaded/image/20166.JPG）。写真が載っているページで撮影日・どの豪雨かを確認し、出典として書く【要確認】。2Dと3Dの水位・浸水範囲を作るときの見た目の参考にもなる（論文や映像に写真そのものを載せる場合は、市の利用条件を確認する）。
> 範囲の決め方は、浸水データを見て、3つの範囲で浸水の深さ・広さが極端に違わないように調整する（難しさをそろえるため）。

**1人の見方**：3つの範囲のうち2つを、1つは2D・1つは3Dで見る。全員に3つすべてを見てもらうと30分を超えて疲れが出るうえ、2Dと3Dの回数がそろわないため。

**割り当て表**：受付で、下の①〜⑥を **順番にくり返して** 割り当てる（1人目＝①、2人目＝②…7人目＝①）。

| パターン | 1回目 | 2回目 | 順番 |
|---|---|---|---|
| ① | X・2D | Y・3D | 2Dが先（A群） |
| ② | Y・2D | Z・3D | 2Dが先（A群） |
| ③ | Z・2D | X・3D | 2Dが先（A群） |
| ④ | X・3D | Y・2D | 3Dが先（B群） |
| ⑤ | Y・3D | Z・2D | 3Dが先（B群） |
| ⑥ | Z・3D | X・2D | 3Dが先（B群） |

- 6人で一巡すると、**どの範囲も「2Dで2回・3Dで2回」「1回目に2回・2回目に2回」使われる**。範囲の難しさ・見る順番の影響が、2Dと3Dの間で打ち消し合う。
- 1人が「2Dでの理解度」と「3Dでの理解度」を1回ずつ持つので、同じ人の中で比べられる。
- 人数はできれば **6の倍数（12人・18人・24人・30人）** にすると、ちょうどそろう。そろわなくても分析はできる（どのパターンが何人だったかを記録しておく）。
- 範囲を3つにした利点：結果が「1つの範囲だけの特徴」ではないと言える。
- 準備するもの：3D映像（3範囲 × 約60秒）、2Dの地図（3範囲）、理解度テスト（3範囲分）、Googleフォーム（6パターン分。共通部分はコピーして作る）。

### 2.3 公平な比較のための条件（ここが一番大事）
2Dと3Dで差が出ても「見せた情報の量が違ったから」と言われると結論が弱くなる。次をそろえる。

| 条件 | そろえ方 |
|---|---|
| 想定する災害 | 同じシナリオ（例：2014年8月豪雨の浸水実績＝市の内水ハザードマップ） |
| 数値 | 2Dの色分けと3Dの水深の色を**同じ凡例**にする（0.5 m／1 m／2 m …） |
| 文字の説明 | 3D映像のテロップ・ナレーションと**同じ文章**を、2Dの地図の横に付ける |
| 見る時間 | 3D映像の長さ（例：60秒）と同じ時間、2Dの地図を見てもらう。時間を計る |
| 見る場所 | 同じ部屋・同じ画面（2Dも同じモニターで表示するのが理想） |
| 地図の出どころ | 市の公式ハザードマップの該当部分（利用条件を市に確認）、または3Dと同じデータから自作 |

> 2Dは静止画、3Dは動画なので、「立体だから」なのか「動くから」なのかは分けられない。限界として考察に書く。

### 2.4 人数ごとのまとめ方

| 集まった人数 | まとめ方 |
|---|---|
| 25〜35人 | 同じ人の中での比較を検定できる（中くらいの差なら見つけられる目安）。集計＋検定＋聞き取り |
| 15〜24人 | 検定はできるが、差が出なくても「差がない」とは言えない。集計と聞き取りを中心に、検定は補足 |
| 10人未満 | 検定はしない。一人ひとりの回答の変化を表にし、聞き取りを中心にまとめる（事例研究として書く） |

- どの場合も、**p値だけでなく「何人中何人が3Dの方が分かりやすいと答えたか」「平均（中央値）がいくつ違ったか」を必ず書く**。
- 1回の調査で集まらなければ、ゼミ・授業・防災講座など **複数回に分けて同じ手順で集めてよい**（回ごとの人数を記録しておく）。

### 2.5 協力者の候補
- 大学のゼミ・授業（福知山公立大学）
- 地域の防災講座、自治会、まちづくりの集まり
- 治水記念館の見学に来た人（記念館の了解を得て）
- 中学生・高校生の場合は、学校・保護者の同意が必要（6章）

## 3. 質問票

回答時間の目安：全体で20〜25分（地図・映像を見る時間を含む）。
評価は5段階：**1 まったくそう思わない／2 あまりそう思わない／3 どちらともいえない／4 ややそう思う／5 とてもそう思う**

### 第1部 事前アンケート（見る前・全員）

**F 属性**
- F1 年齢（10代／20代／30代／40代／50代／60代／70代以上）
- F2 立場（高校生／大学生／社会人／その他）
- F3 お住まい（福知山市内／福知山市外の京都府／京都府外）
- F4 （市内の人）お住まいの地域：町名または小学校区（任意）
- F5 これまでに水害を経験したことがありますか（自宅が浸水した／避難した／周辺で見聞きした／ない）※複数選択可
- F6 福知山市のハザードマップを見たことがありますか（よく見る／見たことがある／存在は知っている／知らない）
- F7 3Dのゲームや3D地図（Googleアースなど）をふだん使いますか（よく使う／ときどき／ほとんど使わない）

**P 事前の知識**

  - a. 川の堤防が壊れて、川の水が街に流れ込むこと
  - b. 街に降った雨が排水しきれず、低い所からたまること【正解】
  - c. 海の水が高潮で街に入ってくること
  - d. わからない
- P3 浸水の深さが何cmになると、大人でも歩いて避難するのが難しくなると思いますか（約10 cm／約50 cm【正解】／約1 m／約2 m／わからない）
- P4 由良川があふれていなければ、福知山の市街地が浸水することはない（そう思う／そう思わない【正解】／わからない）

**R 事前のリスク認知と避難意図**（5段階）
- R1 大雨のとき、自分がよく行く福知山の市街地が浸水する可能性は高いと思う
- R2 福知山の市街地が浸水したら、命にかかわる被害になりうると思う
- R3 自分は水害にあっても大丈夫だと思う ※逆転項目（正常性バイアス）
- R4 大雨のとき、早めに避難しようと思う

### 第2部 アンケート①・②（1つ目を見た後と、2つ目を見た後に、同じ質問）

同じ人が2Dと3Dの両方について答えるので、**①と②は同じ文**にする（②では「今見た資料」についてたずねることを強調する）。

**U 主観的な分かりやすさ**（5段階）
- U1 今見た資料は、浸水の様子が分かりやすかった
- U2 浸水の**深さ**（どのくらいの高さまで水が来るか）がイメージできた
- U3 浸水が**どこから始まり、どう広がるか**がイメージできた
- U4 浸水の深さを、建物や人の背丈と比べてイメージできた
- U5 内容を読み取るのは難しかった ※逆転項目
- U6 この資料を理解するのに、どのくらい頭を使いましたか（1 とても少ない ～ 5 とても多い）

**T 理解度テスト**（①②の両方。見た範囲の問題に答える）
3つの範囲で **同じ形の問題** を作り、地点名と正解だけ変える。【確定後に記入】

| 番号 | 問題の形 | 範囲X（福知山城）の例 | 範囲Y（市民病院）の例 | 範囲Z（桃映中）の例 |
|---|---|---|---|---|
| T1 深さ | ○○の周辺で想定される最大の浸水深は？（0.5 m未満／0.5〜1 m／1〜2 m／2 m以上／わからない） | 城公園の駐車場 | 病院の正面玄関 | 学校の正門 |
| T2 深さの意味 | その深さは建物のどこまで？（足首／ひざ／1階の床上・腰／1階の天井近く／わからない） | 同上 | 同上 | 同上 |
| T3 場所 | 範囲の中で最も早く・深く浸水するのは？（選択肢4つ＋わからない） | 城周辺の候補4か所 | 病院周辺の候補4か所 | 学校周辺の候補4か所 |
| T4 比較 | 地点Aと地点B（図で示す）はどちらが深い？（A／B／同じ／わからない） | 範囲Xの2点 | 範囲Yの2点 | 範囲Zの2点 |

| T7 行動 | この浸水が起きているとき、○○を通って避難するのは安全？（安全／危険／わからない） | 城のふもとの道を歩いて | 病院へ向かう道を車で | 通学路を歩いて |
| T8 確信度 | T1〜T7の答えに、どのくらい自信がありますか（1〜5） | | | |

> 3つの範囲の問題の難しさをそろえることが大事。予備調査で範囲ごとの正答率を見て、極端に違う問題は直す。

> T8（自信）と正答数を両方見ると、「3Dを見て分かったつもりになっただけ」かどうかが分かる。

**R' 見た後のリスク認知と避難意図**（5段階）
- R5 この浸水は、自分や家族にも起こりうることだと感じた（自分事化）
- R6 浸水する前に避難すれば、被害を防げると思う（対処の有効性）
- R7 いざというとき、自分は早めに避難する行動が取れると思う（自己効力感）
- R8 自宅や学校・職場の浸水の深さを、ハザードマップで調べてみようと思う
- R9 この資料を見て、必要以上に不安になった ※副作用
- R10 この資料の浸水の深さは、実際に起こることと同じくらい正確だと思う ※過信の確認

### 第3部 比較アンケート（両方を見た後）

- S1 浸水の**深さ**が分かりやすかったのは（2Dの地図／3Dの映像／同じくらい）
- S2 浸水する**場所（範囲）**が分かりやすかったのは（2D／3D／同じくらい）
- S3 浸水の**広がり方・時間の流れ**が分かりやすかったのは（2D／3D／同じくらい）
- S4 **内水氾濫の仕組み**が分かりやすかったのは（2D／3D／同じくらい）
- S5 **自分のことだと感じた**のは（2D／3D／同じくらい）
- S6 自宅の危険を調べるときに**使いたい**のは（2D／3D／両方／どちらも使わない）
- S7 家族や友人に防災の話をするとき、**見せたい**のは（2D／3D／両方）
- S8 2Dの地図と3Dの映像は、一緒に使うと理解が深まると思う（5段階）
- R1〜R4（事前と同じ文。両方を見た後の変化を見る）
- S9 3Dの映像で分かりやすかったところ・分かりにくかったところ（自由記述）
- S10 2Dの地図で分かりやすかったところ・分かりにくかったところ（自由記述）
- S11 映像を見て、気分が悪くなったり、つらい記憶を思い出したりしましたか（いいえ／少し／はい）※「はい」の人には相談先を案内

### 第4部 聞き取り（5〜8人・1人5〜10分）
少人数の調査では、**数字の理由を説明する生の声が論文の説得力になる**。アンケートの後、了解を得た人に聞く。
被災経験のある人、ハザードマップをよく見る人、3Dに慣れていない人など、**違うタイプの人を選ぶ**。

1. 2Dと3D、最初に見たときの印象はどう違いましたか。
2. 3Dの映像で「これは分かった」と思った場面はどこですか。それはなぜですか。
3. 2Dの地図の方が分かりやすいと思ったところはありますか。
4. 映像を見て、自分の家や通学・通勤路のことを考えましたか。
5. 大雨のとき、いつ・どこへ避難するかの考えは変わりましたか。
6. （被災経験のある人）実際の水害と比べて、映像の水の様子は近いと感じましたか。違うところはどこですか。
7. この映像を、誰に、どんな場面で見せたら役に立つと思いますか。

- 録音する場合は必ず了解を取る。録音しない場合は、その場でメモを取り、直後に清書する。
- 論文では「Aさん（20代・市内在住）」のように匿名で引用する。

## 4. 質問を作るときの注意（チェックリスト）

- [ ] **誘導しない**：「3Dの方が分かりやすかったですよね」のように聞かない。比較の質問は「2D／3D／同じくらい」を必ず並べる。聞き取りでも「3Dはどうでしたか」ではなく「2つを比べてどうでしたか」と聞く。
- [ ] **1つの質問で1つのことだけ聞く**：「分かりやすく、役に立った」のようにまとめない。
- [ ] **逆転項目を入れる**（U5、R3）。
- [ ] **①と②の質問文を同じにする**：同じ人の中で比べるため。
- [ ] **理解テストの正解は公式データで決める**：誰が採点しても同じ点になるよう、採点表を作る。
- [ ] **範囲X・Y・Zの問題の難しさをそろえる**：予備調査で正答率を見て、極端に違えば直す。
- [ ] **割り当て表どおりに割り当てる**：受付で ①〜⑥ を順番に使い、各回答にパターン番号を記録する（フォームを6つに分けるか、最初にパターン番号を選んでもらう）。
- [ ] **市外・県外の人への配慮**：「あなたが市民病院にいたら」のような場面設定の問題を入れる。
- [ ] **専門用語に説明を付ける**：内水氾濫・浸水深・樋門に短い説明を付ける（ただし答えになる説明は付けない）。
- [ ] **予備調査をする**：ゼミの仲間など3〜5人に試してもらい、所要時間・分かりにくい言葉・簡単すぎる問題を直す。予備調査の人は本番の人数に入れない。
- [ ] **疲れに注意**：全体で25分を超えないようにする。長くなる場合は、R'の質問を減らす。

## 5. 分析の方法

| 知りたいこと | データ | 方法 |
|---|---|---|
| 分かりやすさの違い（問1） | U1〜U6 の「2Dでの点」と「3Dでの点」（同じ人） | ウィルコクソンの符号付き順位検定。中央値と「3Dの方が高かった人／同じ／低かった人」の人数 |
| 理解度の違い（問1） | T1〜T7 の2Dでの正答数と3Dでの正答数（同じ人） | ウィルコクソンの符号付き順位検定（または対応のある t 検定） |
| 範囲による違い | 範囲X・Y・Zごとの正答数（2D・3D別） | 範囲ごとの平均を表にし、特定の範囲だけで差が出ていないか確認 |
| 問題の種類ごとの差 | 深さ（T1・T2）、場所（T3〜T5）、内水（T6）、行動（T7） | 種類ごとの正答率を2Dと3Dで並べた表 |
| どちらが選ばれたか（問1） | S1〜S7 | 選んだ人数の集計。「同じくらい」を除いて符号検定（二項検定） |
| 自分事化・避難意図（問2） | R5〜R8 の2Dと3Dの比較、R1〜R4 の事前→比較アンケート時の変化 | ウィルコクソンの符号付き順位検定 |
| 副作用（問3） | R9・R10・S11、T8（自信）と正答数の関係 | 2Dと3Dで比較。自信は高いのに正答が少ない人がいるかを表で確認 |
| 順番の影響 | A群（①②③）とB群（④⑤⑥）の結果 | 群ごとの集計を並べ、順番で大きく違わないか確認 |
| 生の声（問4） | S9・S10・聞き取り | 似た意見をまとめて分類（KJ法）し、代表的な意見を引用 |

- **効果量**（例：r ＝ Z ÷ √人数）を必ず書く。人数が少ないと p値は大きくなりやすいので、「差の大きさ」の方が大事な情報になる。
- 人数が少ないときは、**一人ひとりの「2D→3Dでの変化」を線で結んだ図**（例：U2の点数を左に2D、右に3Dで並べて線で結ぶ）が、検定よりも説得力を持つことが多い。
- 分析ソフト：無料の **JASP** や **jamovi**（クリック操作で符号付き順位検定・効果量が出せる）、またはExcel。
- 注意確認 C1 を間違えた回答は分析から除き、除いた人数を論文に書く。

## 6. 倫理・手続き

- **説明と同意**：調査の目的、所要時間、回答は任意で途中でやめてよいこと、無記名であること、研究目的以外に使わないことを、最初に書く。
- **未成年**：高校生・中学生が対象のときは、学校や保護者の同意が必要か、ゼミの先生と大学の研究倫理の窓口に確認する。
- **被災経験のある人への配慮**：浸水の映像はつらい記憶を呼び起こすことがある。最初に「つらいと感じたら見るのをやめてよい」と伝え、S11で確認する。聞き取りでは、話したくないことは話さなくてよいと伝える。
- **聞き取りの録音**：了解を取る。データは研究終了後に削除する。
- **映像酔い**：画面を大きくしすぎない、カメラを急に動かさない。
- **使用素材の許可**：市のハザードマップの画像を使う場合は、市の利用条件を確認する。

## 7. 論文に書く限界（あらかじめ想定しておく）
- 人数が少なく、協力者が大学生など一部に偏るため、結果を福知山市民全体に当てはめることはできない（探索的な検証）。
- 見た直後の「避難しようと思う」は、実際に避難するかとは別（意図と行動のずれ）。
- 全員が両方を見るため、2つ目を見るときは1つ目の内容が頭に残っている。順番を入れ替えて打ち消しているが、完全には消せない。
- 2Dは静止画、3Dは動画なので、「立体だから」なのか「動くから」なのかは分けられない。
- 3D映像の水面は一枚の平面で、場所ごとの水深の違いを完全には表せない（企画書4.4参照）。
- 範囲によって浸水の様子が違うため、問題の難しさを完全にはそろえられない。割り当て表で2Dと3Dに均等に振り分けて打ち消しているが、人数が6の倍数でないと少し偏る。
