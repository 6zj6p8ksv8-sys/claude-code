# アンケート設計書：3D浸水可視化映像は2Dハザードマップより分かりやすいか

研究題目：福知山市中心市街地における内水氾濫の3D可視化と**防災啓発ツールとしての有効性**に関する研究
作成：2026-10-18（案）

> この設計書は、企画書 README.md の 10章「効果の検証」を詳しくしたもの。
> **【確定後に記入】** は、映像・地図に使う浸水深などの数値が決まってから正解を入れる項目。

---

## 1. 何を確かめるか（研究の問いと仮説）

「分かりやすい」を、本人の感想だけで測ると「3Dの方が新しくて面白かった」という印象の差しか分からない。防災啓発ツールとしての有効性を言うために、次の **5つの面** から測る。

| 面 | 何を見るか | 測り方 |
|---|---|---|
| ① 客観的な理解 | 浸水の深さ・場所・順番・内水と外水の違いを**正しく読み取れたか** | 正解のあるテスト（正答数） |
| ② 主観的な分かりやすさ | 本人が分かりやすいと感じたか、読み取るのが大変だったか | 5段階評価＋負担感 |
| ③ リスクの自分事化 | 危険を「自分のこと」と感じたか（深刻さ・起こりやすさ） | 5段階評価 |
| ④ 避難の意図 | 早めに避難しよう、自宅の危険を調べようと思ったか | 5段階評価 |
| ⑤ 副作用 | 怖がらせすぎ、誤解（3Dの見た目を正確だと思い込む）、酔い | 5段階評価＋自由記述 |

**仮説**
- H1：3D映像を見た人は、2Dハザードマップを見た人より、①客観的理解テストの正答数が多い（とくに「高さ」と「時間の順番」の問題）。
- H2：3D映像の方が、②主観的な分かりやすさが高く、読み取りの負担感が低い。
- H3：3D映像の方が、③リスクの自分事化と④避難意図が高まる。
- H4：内水氾濫（川があふれていなくても街が浸水する）の理解は、3D映像の方が深まる。

> 「3Dの方がすべて良い」とは限らない。たとえば「地図上のどこが危ないか（平面の位置）」は2Dの方が読み取りやすい可能性もある。**差が出なかった項目も結果として書く**ことで、研究の信頼性が上がる。

### 理論的な枠組み（卒論の先行研究で引用できるもの）
- **防護動機理論（Protection Motivation Theory, Rogers 1983）**：人が避難などの行動を取るかは「脅威評価（深刻さ・起こりやすさ）」と「対処評価（避難が有効だと思うか・自分にできると思うか）」で決まる、という考え方。日本の避難意図の研究でもよく使われている。③④の質問はこの枠組みで作る。
- **正常性バイアス**：中間レポート1.2節で触れている。「自分は大丈夫」と思う度合いを質問に入れる。

## 2. 調査の設計

### 2.1 推奨：2グループ・順番入れ替え方式

```
全員：同意 → 事前アンケート（属性・事前テスト）
        │
   ランダムに2群に分ける
   ├─ A群：2Dハザードマップ → 中間アンケート① → 3D映像 → 事後アンケート②
   └─ B群：3D映像 → 中間アンケート① → 2Dハザードマップ → 事後アンケート②
```

- **主な比較は「中間アンケート①」で行う**（A群＝2Dだけ見た人、B群＝3Dだけ見た人）。両方見た後だと、先に見たものの影響が混ざるため。
- **事後アンケート②**では、両方を見た上で「どちらが分かりやすかったか」を直接たずねる。順番の影響は、A群とB群を比べれば分かる。
- 事前テストを取っておくと、もともとの知識の差を調整できる（共分散分析）。

### 2.2 公平な比較のための条件（ここが一番大事）
2Dと3Dで差が出ても、「見せた情報の量が違ったから」と言われると結論が弱くなる。次をそろえる。

| 条件 | そろえ方 |
|---|---|
| 想定する災害 | 同じシナリオ（例：2014年8月豪雨の浸水実績＝市の内水ハザードマップ）、同じ範囲（駅南〜市民病院周辺） |
| 数値 | 2Dの色分けと3Dの水深の色を**同じ凡例**にする（0.5 m／1 m／2 m …） |
| 文字の説明 | 3D映像のテロップ・ナレーションと**同じ文章**を、2Dの地図の横に印刷して付ける |
| 見る時間 | 3D映像の長さ（例：60秒）と同じ時間、2Dの地図を見てもらう。時間を計る |
| 見る場所 | 同じ部屋・同じ画面サイズ（2Dも同じモニターで表示するのが理想） |
| 地図の出どころ | 2Dは市の公式ハザードマップの該当部分を使う（著作権の扱いを市に確認）。自作するなら3Dと同じデータから作る |

> 3D映像は「立体」と「動き（時間変化）」の2つの要素を持つ。どちらが効いたかを分けたい場合は、余力があれば第3群「3Dの静止画」を加える（人数が足りなければ、限界として考察に書く）。

### 2.3 人数の目安
- 2群の差（効果量 d = 0.5、有意水準 5%、検出力 80%）を見るには、**1群あたり約64人（計約130人）**。
- 現実的に集めにくい場合、1群30人程度でも分析は可能。ただし「小さな差は検出できない」ことを限界に書き、**効果量（d）と信頼区間を必ず報告**する。
- 対象候補：大学のゼミ・授業（福知山公立大学）、オープンキャンパス来場者、地域の防災講座、桃映中学校（学校・保護者の同意が必要）。

### 2.4 ランダムな割り当て
- Googleフォームを2つ（A用・B用）作り、受付で **A・B を交互に配る**（QRコードを交互に渡す）。
- 誕生月の奇数・偶数で分ける方法もある。グループの偏り（年齢・居住地）は属性で確認する。

### 2.5 遅延テスト（任意・あると強い）
1〜2週間後に、理解テストと避難意図の一部を**もう一度**答えてもらう（メールアドレスを任意で回収。回答とは別に管理）。「見た直後だけでなく、記憶に残るか」が分かる。

## 4. 質問を作るときの注意（不十分を防ぐチェック）

- [ ] **誘導しない**：「3Dの方が分かりやすかったですよね」のような聞き方をしない。比較の質問は「2D／3D／同じくらい」を必ず並べる。選択肢の並び順を回答者ごとに入れ替えられるなら入れ替える。
- [ ] **1つの質問で1つのことだけ聞く**：「分かりやすく、役に立った」のように2つをまとめない。
- [ ] **逆転項目を入れる**（U5、R3）：何も考えずに全部「5」をつける回答を見つけやすい。
- [ ] **理解テストの正解は公式データで決める**：映像・地図と同じ数値から作る。誰が採点しても同じ点になるように、採点表を作っておく。
- [ ] **事前・中間・遅延テストは同じ種類の別問題**：同じ問題だと「2回目だから覚えていた」となる。
- [ ] **市外・県外の人への配慮**：「自分の家」が対象範囲に無い人もいるので、「あなたが市民病院にいたら」のような場面設定の問題も入れる（T8 など）。
- [ ] **専門用語に説明を付ける**：内水氾濫・外水氾濫・アンダーパス・浸水深は、問題文に短い説明を付ける（ただしテストの答えになる説明は付けない）。
- [ ] **予備調査をする**：本番前に5〜10人に試してもらい、所要時間、分かりにくい言葉、正答率が高すぎる（簡単すぎる）問題を直す。
- [ ] **自由記述を必ず入れる**：数字では分からない「なぜ分かりやすかったか」を拾える。

## 5. 分析の方法

| 知りたいこと | データ | 方法 |
|---|---|---|
| 2Dと3Dで理解度に差があるか（H1） | 中間①の T1〜T9 正答数（A群 vs B群） | 対応のない t 検定（分布が偏っていればマン・ホイットニーのU検定）。事前テストの点を調整するなら共分散分析（ANCOVA）。効果量 d を報告 |
| 問題の種類ごとの差 | T の各問の正答率（深さ・場所・時間・内水） | χ²検定（またはフィッシャーの正確確率検定） |
| 分かりやすさ・負担感の差（H2） | U1〜U6 | マン・ホイットニーのU検定（5段階は順序尺度として扱う） |
| リスク認知・避難意図が上がったか（H3） | R1〜R4 の事前→中間の変化 | ウィルコクソンの符号付き順位検定（群内）、変化量の群間比較 |
| 直接比較でどちらが選ばれたか | S1〜S7 | 選ばれた割合の集計と二項検定。A群・B群で比べて順番の影響を確認 |
| 分かったつもりになっていないか | 正答数と T10（自信）の関係、R10 | 群ごとの相関・散布図 |
| 誰に効くか | F5〜F7（被災経験・ハザードマップ経験・3D慣れ）別 | 層別の集計（人数が少なければ記述だけ） |
| 自由記述 | S9・S10 | KJ法やキーワードの集計で分類し、代表的な意見を引用 |

- 尺度（例：R5〜R8 を「避難意図」としてまとめる）を使う場合は、クロンバックのα係数で内的一貫性を確認する。
- 分析ソフト：無料の **JASP** や **jamovi**（クリック操作で t 検定・ANCOVA・効果量が出せる）、またはExcel／R。
- 注意確認 C1 に間違えた回答は、分析から除く（除いた人数を論文に書く）。

## 6. 倫理・手続き

- **説明と同意**：調査の目的、所要時間、回答は任意で途中でやめてよいこと、無記名であること、研究目的以外に使わないことを、最初のページに書く。
- **未成年**：高校生・中学生が対象のときは、学校や保護者の同意が必要か、ゼミの先生と大学の研究倫理の窓口に確認する。
- **被災経験のある人への配慮**：浸水の映像はつらい記憶を呼び起こすことがある。最初に「つらいと感じたら見るのをやめてよい」と伝え、S11で確認する。
- **個人情報**：遅延テスト用のメールアドレスは回答データと別に保存し、調査後に削除する。
- **映像酔い**：画面を大きくしすぎない、カメラを急に動かさない。F8 の人には座って見てもらう。
- **使用素材の許可**：市のハザードマップの画像を使う場合は、市の利用条件を確認する。

## 7. 論文に書く限界（あらかじめ想定しておく）
- 対象者が大学生・オープンキャンパス来場者に偏ると、高齢者など避難で支援が必要な人への効果は分からない。
- 見た直後の「避難しようと思う」は、実際に避難するかとは別（意図と行動のずれ）。
- 3D映像の水面は一枚の平面で、場所ごとの水深の違いを完全には表せない（企画書4.4参照）。
- 2Dは静止画、3Dは動画なので、「立体だから」なのか「動くから」なのかは分けられない（第3群を置かない場合）。
