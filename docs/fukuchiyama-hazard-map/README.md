## 1. 企画概要

### 1.1 目的
福知山市街地で過去に起きた水害を、3D映像で「自分の生活圏の高さ」として見せる。とくに一般の人に区別がつきにくい

- **内水氾濫**：まちに降った雨が川へ排水しきれず、低い所から水がたまる浸水
- **外水氾濫**：由良川など川の水位が上がり、堤防を越える／堤防が切れて市街地へ流れ込む浸水

の違いを、映像の動きで直感的に理解してもらう。最後に、両方が重なる「複合型」のイメージを示す。

### 1.2 想定する視聴者・用途
- 地域住民、学校（桃映中学校の防災学習など）、病院職員・利用者
- 防災講座、学校発表、SNS・動画サイト掲載（尺は 3〜5 分を想定）

### 1.3 映像の柱（3本＋合成）

| パート | 内容 | 主な参照事例 |
|---|---|---|
| A. 内水氾濫編 | 豪雨 → 側溝・水路があふれる → 低地から水位が上がる。由良川はまだあふれていない | 平成26年（2014年）8月豪雨（いわゆる「福知山豪雨」） |
| B. 外水氾濫編 | 上流の大雨で由良川の水位が上がる → 堤防を越える／決壊 → 濁流が勢いよく市街地へ | 平成25年（2013年）台風18号、平成16年（2004年）台風23号、昭和28年（1953年）台風13号 |
| C. 複合編 | 由良川の水位が高く樋門（ひもん）が閉じられる → 支川・下水が排水できず内水が増える → さらに外水も加わる | 2014年8月豪雨の府資料の分析、想定最大規模 |
| D. 比較・まとめ | 3地点の「最大でどこまで来るか」を人・建物と並べて比較し、避難の判断（垂直避難・早めの避難）につなげる | 市の防災マップ |

## 2. 過去の水害データ（水位の数値を決めるための資料）

### 2.1 由良川・福知山観測所の主な最高水位

| 年 | 出来事 | 福知山地点の最高水位 | 備考 |
|---|---|---|---|
| 1953（昭和28） | 台風13号 | **7.80 m** | 死者36名、床上浸水5,307戸、床下2,458戸（資料により死者・行方不明37人）。福知山地点流量 約6,500 m³/s。現在の治水計画の基準になった洪水 |
| 2004（平成16） | 台風23号 | **7.55 m** | 戦後では1953年に次ぐ水位。由良川流域で死者5名、床上1,251戸、床下418戸 |
| 2013（平成25） | 台風18号 | **8.30 m**（速報値） | 観測史上最高。計画高水位 7.74 m を上回った |
| 2014（平成26） | 8月豪雨 | **6.48 m**（5:10） | 由良川本川は上の3例より低いのに、市街地は大規模な内水浸水 → **内水氾濫の代表例** |
| 2017（平成29） | 台風21号 | 2004年に匹敵 | 下流部の輪中堤の効果で浸水は抑えられた |

※ 水位は観測所の「水位標の読み（m）」であり、地面からの浸水深ではない。映像では「標高（T.P.）」に換算してから使う（4.3 参照）。【要確認：各年の T.P. 換算値、零点高】

### 2.2 平成26年8月豪雨（内水氾濫の代表例）

- 雨量：福知山（府）観測所で **60分最大 75 mm、24時間 343 mm**。市内で観測史上最大
  - 別の資料：福知山観測所で 335 mm/2日、8月15日2時〜17日24時の降水量 357.5 mm
- 被害（集計範囲で数字が違うので、使う時は出典を明記）
  - 市の速報（8/22時点）：床上 1,183棟、床下 1,324棟、計 2,507棟、**浸水面積 7.5 km²**
  - 弘法川・法川流域（10/1時点 市調べ）：床上 1,586戸、床下 1,712戸
  - 福知山市全域（8/15集中豪雨）：床上 1,995、床下 2,430 とする表もある
- 原因（京都府資料の分析）
  - 局地的・集中的な豪雨
  - **由良川本川のピークと支川（弘法川・法川）の出水が重なった**
  - 樋門を閉じたことで、内水排除施設（ポンプ）の能力を上回った
  - 下水道の排水能力を超えた
- 流域：弘法川 15.1 km²、法川 3.3 km²
- 市民病院は、弘法川・法川の周辺、**和久市ポンプ場の近く**にあり、府・国の資料の浸水範囲図にも描かれている。対策として和久市ポンプ場の耐水化なども盛り込まれた。
- その後の対策：国・府・市が連携し、平成27年〜令和2年に弘法川・法川の改修、調節池、ポンプ施設（荒河排水機場・弘法川排水機場の増強など）を整備。国は「2014年8月豪雨と同程度の雨で床上浸水をおおむね解消する」ことを目標とした（床上浸水対策特別緊急事業、2020年完了報告）。

> **映像上のポイント**：2014年は「由良川の水位は 6.48 m で、過去の大洪水より低かった」のに、市街地が広く浸水した。これは内水氾濫を説明する一番わかりやすい材料になる。
> また「対策後の現在」と「2014年当時」を並べる演出も考えられる（ただし、現在の対策効果を映像化する場合は、行政の公表資料にもとづくこと）。

### 2.3 市街地の内水浸水が起きた年
国の資料では、福知山市街地で **2004年10月（台風23号）、2013年9月（台風18号）、2014年8月（集中豪雨）** に内水浸水が起きたとされている。外水の大きい年にも内水は起きている＝複合編の根拠になる。

### 4.3 水位の数値の決め方（作業手順）
1. **地形の基準をそろえる**：すべて標高（東京湾平均海面 T.P.）で扱う。
2. **外水**：由良川の水位標の値 → 観測所の零点高を足して T.P. に換算 → 堤防天端高と比べる。浸水想定図の「浸水深」は「地面からの深さ」なので、各地点では「地盤標高 ＋ 浸水深 ＝ 水面の標高」として水面を置く。
3. **内水**：低地ほど深くなるので、一枚の水平な水面ではなく、**内水ハザードマップの浸水深をメッシュごとに読む**のが正確。簡易版なら「浸水区域の中で、地盤が低い順に水面が上がる」表現にする。
4. 演出のために数値を丸める・誇張する場合は、映像のどこかに「数値は〇〇の資料をもとにした目安」と出す。

## 5. 住民の体験談・リアルな証言の集め方

公開資料ですぐ見つかるものは限られている。以下の順に当たるのがおすすめ。

1. **福知山市治水記念館**：被災者の体験談映像を常設で流している。語り部（例：芦田卓さん）が来館者に体験を語っている。「NIPPON防災資産」に認定。→ 見学・取材の申し込み、映像を使う場合は利用許可を取る。
2. **国土交通省 福知山河川国道事務所**：2024年に台風23号から20年の特別パネル展「未来に繋ぐ記録」（福知山市・舞鶴市）を開き、被災者の体験談を展示した。→ 展示資料の提供をお願いする。
3. **由良川減災対策協議会**（国・府・市町）の資料、**京都府・福知山市の災害記録**
4. **論文・調査報告**：立命館大学の研究報告（福知山の水害の聞き取り）、京都大学防災研究所年報（2004年台風23号の調査報告。「過去の水害を凌ぐ急激な水位上昇」と指摘）
5. **新聞の地域面**：両丹日日新聞、京都新聞（丹波・中丹版）の当時の記事・写真
6. **自分で聞き取りをする場合**
   - 桃映中学校の生徒が家族・地域の人に聞く／病院職員に聞く、という形は学習にもなる
   - 聞くこと：その日の時刻ごとの行動、水が「どこから」「どのくらいの速さで」来たか（＝内水か外水かの判断材料）、家のどこまで水が来たか（床上〇cm）、においや音、停電、避難のきっかけ、困ったこと、今だから言えること
   - **同意書**（名前・顔・声を映像に使うか）を必ず取る。被災のつらい記憶に関わるので、話したくないことは話さなくてよいと最初に伝える
   - 映像に入れるのは「〇〇町・70代の方」程度の表記にとどめるのが無難

> 体験談は「水の深さ」の検証にも使える。「玄関の段差まで来た」「車のタイヤが半分」などの証言を、映像の水位と照らし合わせて表現をそろえる。

## 6. 映像構成案（絵コンテメモ）

### 6.0 オープニング（約20秒）
- 福知山城の上空からゆっくり降りる。由良川、土師川、市街地、3地点にピンを立てる
- テロップ：「もし、この街に水が来たら」

### 6.1 A. 内水氾濫編（約60秒）
1. 空が暗くなる。強い雨（パーティクル）。由良川はまだ堤防の中
2. 道路の側溝・マンホールから水がにじみ出る → 交差点・アンダーパス・低い土地にたまる
3. 弘法川・法川などの支川の水位が上がる。樋門を閉める演出（本川の水が逆流しないように）→ 排水が追いつかない
4. 低い所から順に水面が広がる（**流れは遅く、静かに、じわじわ**）。市民病院の周辺が浸かっていく
5. テロップ：「2014年8月　1時間に75mm／24時間で343mm　由良川の水位は6.48m（過去の大洪水より低い）　それでも約7.5km²が浸水」
6. **見せ方のキーワード**：「川からではなく、足元からわく水」

### 6.2 B. 外水氾濫編（約60秒）
1. 上流に雨雲、晴れ間のある市街地でも由良川の水位がぐんぐん上がる（上流の雨で来る＝「ここが雨でなくても来る」ことも伝える）
2. 水位計の表示：6 m → 7 m → 7.74 m（計画高水位）→ 8.30 m（2013年）
3. 堤防を越える（越水）→ 堤防の裏側が削れる → 決壊
4. 濁流が**速く、勢いよく、茶色く**市街地へ。がれき・流木を流す。家屋倒壊等氾濫想定区域の演出
5. 福知山城の丘は水に浮かぶ島のように残る
6. **見せ方のキーワード**：「川から一気に押し寄せる水」

### 6.3 C. 複合編（約60秒）
1. 内水でたまった状態（A の終わり）から始める
2. 由良川の水位が上がり、樋門が閉じたまま → ポンプの能力を超えて内水がさらに増える
3. そこへ外水が加わる → 水面が一段上がり、流れも速くなる
4. 画面を分割：左＝内水だけ／中＝外水だけ／右＝両方
5. テロップ：「公式のハザードマップは、内水と外水が別々に作られています。実際の災害では重なることがあります（この映像はイメージです）」

### 6.4 D. 比較・まとめ（約40秒）
- 3地点を並べ、人（170 cm）・1階の天井（約2.5 m）・2階の床（約3 m）・車のスケールと並べて最大水位を比較
- 「浸水深 0.5 m＝大人の膝〜腰／歩いて避難が難しい」「3 m＝2階の床」など、国の基準の浸水深の目安を出す
- 呼びかけ：自分の家・学校の場所をハザードマップで見る／早めの避難／垂直避難の判断
- 出典の一覧をエンドロールで出す

## 7. Blender 制作メモ

### 7.1 地形・建物データ
| データ | 入手先 | 用途 |
|---|---|---|
| 数値標高モデル（DEM）5 mメッシュ | 国土地理院 基盤地図情報 | 地形（高さの精度が大事。市街地は5 m推奨） |
| 3D都市モデル | **国土交通省 PLATEAU**【要確認：福知山市が整備対象かどうか】 | 建物（ない場合は OpenStreetMap の建物形状＋階数で押し出し） |
| 航空写真・地図タイル | 国土地理院 地理院タイル | 地形の色・テクスチャ |
| 河川・堤防の形状 | 国土数値情報（河川）、OSM | 堤防の高さは別途、河川事務所資料で確認 |
| 浸水想定区域データ | 国土数値情報「洪水浸水想定区域」（GIS形式） | 浸水深のメッシュを水面の高さに変換 |

- アドオン：**BlenderGIS**（DEM・OSM の読み込み、座標系の設定）。PLATEAU を使う場合は CityGML/FBX/OBJ 版を読み込むか、PLATEAU用のインポーターを使う
- 座標系：平面直角座標系 第VI系（京都府）でそろえる
- 高さの誇張：地形が平らに見えるなら Z を 1.5〜2 倍にする手もあるが、**水位の比較が狂う**ので、使う場合は画面に「高さ方向〇倍」と出す。比較パート（D）は等倍が望ましい

### 7.2 水の表現
| 種類 | 手法 | 見た目 |
|---|---|---|
| 内水 | 水平な Plane の Z 位置をキーフレームで上げる＋ Boolean／地形でマスク。または浸水深メッシュを高さマップにして Displace | 静か、波少なめ、泥色うすめ、道路の白線が透けて見える |
| 外水 | Mantaflow（流体シミュレーション）を決壊点周辺だけで使う。全体は Plane＋Geometry Nodes で水面が広がる演出に | 速い流れ、白波、茶色く濁る、流木 |
| 雨 | パーティクル、または画面合成（コンポジット）の雨 | |
| 浸水の広がり | 浸水ナビの時間経過を参考に、Geometry Nodes で「決壊点からの距離×時間」で水面をマスク | |

- 浸水深の色分けは、国の凡例（0.5 m未満／0.5〜3 m／3〜5 m／5〜10 m／10 m以上）に合わせると、ハザードマップと見比べやすい
- 水位ゲージ（画面の端の水位計）は Geometry Nodes か、After Effects 等の合成で
- レンダリング：EEVEE（速い、試作向け）→ 本番は Cycles。尺 3〜5 分なら EEVEE＋部分的に Cycles が現実的

### 7.3 内水と外水の「見分けがつく」デザイン
- **色**：内水＝青みのある半透明、外水＝茶色く不透明（実際の外水は泥水）
- **動き**：内水＝ゆっくり、下から上へ／外水＝速く、川から横へ
- **音**：内水＝雨音・排水口のゴボゴボ音／外水＝ゴーという濁流の音
- **カメラ**：内水＝人の目の高さ（足元が浸かる怖さ）／外水＝上空（広がる速さ）
- 凡例アイコンを決めて、全編で同じものを使う
